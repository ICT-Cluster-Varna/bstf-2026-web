# Спецификация: Добавяне на партньор — LAZUR (Мебелна палата)

**Дата:** 2026-09-10
**Приоритет:** Нормален
**Тип:** Ново съдържание — партньорско лого

---

## Описание

Добавяне на **LAZUR — Мебелна палата** като партньор в секция „Партньори" (`partner-row` с лейбъл „Партньори / Partners") в `index.html` (BG) и `en/index.html` (EN).

Логото е предоставено (червен надпис „LAZUR" + „МЕБЕЛНА ПАЛАТА").

---

## Текущо състояние на секцията

Редът „Партньори" в момента съдържа 3 лога:
- **BULTİŞAD** (`partner-logo--bultisad`)
- **БАСЕЛ** (`partner-logo--basel`)
- **Българо-Румънска търговска камара** (`partner-logo--brcc`)

LAZUR се добавя като **4-ти** елемент в същия ред.

Партньорските лога (без bultisad) използват генеричния стил `.partner-logo img { height: 64px; width: auto; max-width: 190px; object-fit: contain; }` — затова **не е задължителен нов CSS**.

---

## Задачи за разработчика (Симо)

### Задача 1 — Качване на логото

Запиши предоставеното лого като:
`images/partner-lazur.png`

**Обработка:**
- Изрежи излишните бели полета около логото (в предоставения файл има голям бял кант).
- Прозрачен или бял фон. Препоръчителна ширина ~600 px, макс. ~60 KB.
- Запомни реалните пиксели (ширина×височина) за `width`/`height` атрибутите.

---

### Задача 2 — HTML в `index.html` (BG, ред ~5659)

В блока „Партньори", **след** `partner-logo--brcc` (ред ~5659, преди затварящия `</div>` на `partner-row__logos`), добави:

```html
              <div class="partner-logo partner-logo--lazur">
                <a href="TODO_WEBSITE_URL" target="_blank" rel="noopener">
                  <img src="images/partner-lazur.png?v=20260910" alt="LAZUR — Мебелна палата" loading="lazy"
                    decoding="async" width="TODO_W" height="TODO_H">
                </a>
              </div>
```

---

### Задача 3 — HTML в `en/index.html` (EN, ред ~5636)

Същият блок, на същото място (след `partner-logo--brcc`), но с префикс `../` в `src`:

```html
              <div class="partner-logo partner-logo--lazur">
                <a href="TODO_WEBSITE_URL" target="_blank" rel="noopener">
                  <img src="../images/partner-lazur.png?v=20260910" alt="LAZUR — Furniture Palace" loading="lazy"
                    decoding="async" width="TODO_W" height="TODO_H">
                </a>
              </div>
```

> `alt` на EN: „LAZUR — Furniture Palace" (или остави „LAZUR — Мебелна палата", ако предпочитате да не се превежда).

---

### Задача 4 — (по избор) CSS фина настройка

LAZUR е широко (landscape) лого. Ако при `max-width: 190px` изглежда твърде малко до другите, добави в `<style>` блока на **двата** файла, след `.partner-logo--bultisad img { ... }`:

```css
      .partner-logo--lazur img {
        height: 52px;
        max-width: 200px;
      }
```

Провери визуално и коригирай стойностите.

---

### Задача 5 — Cache-busting

Новото `<img>` вече носи `?v=20260910`. Ако при редакцията се пипат други версионирани ресурси (`shared/site-chrome.js`, `og-cover.jpg`), обнови техните `?v=` до `20260910` съгласно `CLAUDE.md`.
